# 喻园拾光——华科校园生活指南


“喻园拾光”是一个以华中科技大学校园生活为主题的静态网页项目，用校园照片和文字记录校园风景、学习、美食、课余活动与个人成长。网站采用手写的 HTML、CSS 和少量 JavaScript 制作，不需要安装依赖或运行构建工具。


**在线预览：** https://augsven.github.io/yuyuan-campus/

**GitHub 仓库：** https://github.com/AugSven/yuyuan-campus


## 网站页面


网站共有六个相互链接的页面，顶部导航可在页面间切换，各分页面也提供返回首页的链接。











































| 页面 | 文件 | 内容 |
| --- | --- | --- |
| 首页 | `index.html` | 网站介绍、四个主题入口、成长寄语及动态主视觉 |
| 校园风景 | `web/campus.html` | 校园地标、散步建议和八张校园照片 |
| 学习生活 | `web/study.html` | 学习空间、学习节奏建议和相关照片 |
| 华科美食 | `web/food.html` | 九张美食照片及对应介绍，并提供微信公众号文章链接 |
| 课余生活 | `web/life.html` | 社团、迎新、志愿服务、读书交流等活动照片 |
| 温暖与成长 | `web/growth.html` | 戚志鹏同学《我心中的华科大精神》主题文章的分段整理 |

## 主要设计与交互


- **校园手帐风格：** 使用暖色纸张底色、柔和色彩、不规则边角和错落的图片排布，避免每个页面都呈现相同的卡片模板。
- **个性化图标：** 首页主题入口和分页面标题使用原创线描 SVG 图标，分别呼应校园、阅读、美食、活动与成长主题。
- **校园照片背景：** 新增的校园照片作为全站背景，并叠加浅色遮罩，营造氛围的同时保持文字清晰。
- **首页微风动画：** 首页主视觉包含缓慢移动的云朵和摆动的小草；鼠标移动时，部分元素会有轻微响应。可以点击“暂停微风 / 继续微风”控制动画。
- **响应式布局：** 针对窄屏调整导航、图片网格和内容布局，方便在手机上浏览。
- **减少动态效果支持：** 用户设备启用“减少动态效果”偏好时，动画会停用。


## 如何在电脑上打开


1. 将整个 `MyWeb` 文件夹保存到电脑。
2. 打开文件夹，双击 `index.html`。
3. 使用现代浏览器查看网页。


请保留 `css`、`image`、`web` 文件夹与首页之间的相对位置。只移动或发送 `index.html` 会导致样式、图片或页面链接无法正常显示。


## 如何修改内容


### 修改文字


使用文本编辑器或代码编辑器打开相应的 HTML 文件，修改页面正文中的文字，然后保存。


例如：


- 首页内容：`index.html`
- 美食介绍：`web/food.html`
- 成长文章：`web/growth.html`


请尽量保留 HTML 标签结构，例如 `<h1>`、`<p>`、`<a>` 和 `<img>`，避免误删页面布局所需的标签。


### 更换或添加图片


1. 将图片放入 `image` 文件夹。
2. 在 HTML 中找到对应的 `<img>` 标签。
3. 将 `src` 改为相对路径，例如：`../image/my-photo.jpg`。
4. 将 `alt` 改为图片内容的简短描述，方便使用辅助技术的访客理解图片。


首页图片路径从根目录开始，例如 `image/campus-main-gate.jpg`；`web` 文件夹里的页面引用图片时，通常使用 `../image/文件名`。


### 调整整体样式


全站样式保存在 `css/style.css`。可以在其中修改背景、字体、间距、颜色、图片布局和移动端规则。各网页通过相对路径引用这份样式表。


## 发布与更新


网站通过 **GitHub Pages** 发布。在线版本的网址为：


https://augsven.github.io/yuyuan-campus/


更新网站时，将修改后的网页文件和素材上传到 GitHub 仓库的 `main` 分支。GitHub Pages 会根据仓库根目录中的 `index.html` 更新网站；部署可能需要几分钟。如果浏览器仍显示旧样式，可尝试强制刷新页面。


## 相关素材来源说明


- 校园、课余活动和美食照片来自网站制作者提供的素材。
- 《我心中的华科大精神》依据戚志鹏同学提供的文章进行分段整理。
- 美食页和学习页提供了微信公众号文章的延伸阅读链接；页面中的介绍不应视为对公众号原文的逐字摘录。


## 公开分享前请留意


网站可通过公开网址访问。成长页面含有作者姓名、班级和个人经历；网站图片也可能包含其他同学。公开分享前，请确认相关文字与照片均适合公开展示，并已获得所需授权。
